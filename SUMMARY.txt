1. ЗАМЕНА ТЕХНОЛОГИИ РЕРАЙТА
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   
   Было (OpenAI):
   • Зависимость от внешнего API
   • Платная подписка ($0.002/1K токенов)
   • Требуется интернет постоянно
   • Данные отправляются на серверы OpenAI
   • Лимиты на количество запросов
   
   Стало (Ollama):
   • Локальная LLM на вашем сервере
   • Полностью бесплатно
   • Работает офлайн (после загрузки модели)
   • Все данные остаются локально
   • Без лимитов на запросы

API OLLAMA:
   
   Endpoint: http://ollama:11434/api/generate
   Method:   POST
   Payload:  {
               "model": "llama3.2",
               "prompt": "...",
               "stream": false,
               "options": {
                 "temperature": 0.8,
                 "num_predict": 2000
               }
             }
   
   Response: {
               "response": "сгенерированный текст",
               "eval_count": количество_токенов,
               "eval_duration": время_в_наносекундах
             }

СИСТЕМНЫЕ ТРЕБОВАНИЯ:

   Минимальные (для llama3.2):
   • CPU: 4 ядра
   • RAM: 8GB
   • Диск: 10GB
   • Скорость: ~10-15 tok/s
   
   Рекомендуемые (для mistral/qwen2.5):
   • CPU: 8 ядер
   • RAM: 16GB
   • Диск: 20GB
   • Скорость: ~15-20 tok/s
   
   С GPU (для любой модели):
   • NVIDIA GPU (8GB+ VRAM)
   • nvidia-docker2
   • Скорость: 3-5x быстрее

БЫСТРЫЙ СТАРТ:

   1. Запустите все сервисы:
      $ docker compose up -d
   
   2. Дождитесь запуска Ollama (30-60 секунд):
      $ docker compose logs -f ollama
   
   3. Загрузите модель (первый раз, ~2-5GB):
      $ docker compose exec ollama ollama pull llama3.2
   
   4. Проверьте установленные модели:
      $ docker compose exec ollama ollama list
   
   5. Настройте .env (если не сделали):
      OLLAMA_MODEL=llama3.2
      WORDPRESS_API_USER=ваш_пользователь
      WORDPRESS_API_PASSWORD=ваш_application_password
   
   6. Перезапустите article-service:
      $ docker compose restart article-service
   
   7. Проверьте логи:
      $ docker compose logs -f article-service
      # Должно быть: "Ollama доступен. Доступные модели: ['llama3.2']"
