# Миграция с OpenAI на локальную LLM (Ollama)

Этот файл содержит инструкции для миграции с OpenAI API на локальную LLM.

## Что изменилось?

### ✅ Преимущества
- **Бесплатно**: Не нужно платить за OpenAI API
- **Приватность**: Данные не покидают ваш сервер
- **Без лимитов**: Нет ограничений на количество запросов
- **Офлайн**: Работает без интернета (после загрузки модели)

### ⚠️ Требования
- **RAM**: Минимум 8GB (для моделей 3-7B)
- **Диск**: ~10-20GB для моделей
- **CPU/GPU**: Генерация может быть медленнее без GPU

## Шаги миграции

### 1. Обновите код из репозитория

```bash
git pull origin main
```

### 2. Удалите старые переменные из .env

Удалите или закомментируйте:
```env
# OPENAI_API_KEY=...
# OPENAI_MODEL=...
```

### 3. Добавьте новые переменные Ollama

Добавьте в `.env`:
```env
# Ollama настройки
OLLAMA_URL=http://ollama:11434
OLLAMA_MODEL=llama3.2
```

### 4. Пересоберите контейнеры

```bash
# Остановите старые контейнеры
docker compose down

# Пересоберите article-service
docker compose build article-service

# Запустите все сервисы (включая новый Ollama)
docker compose up -d
```

### 5. Загрузите модель для Ollama

```bash
# Рекомендуемая модель для начала
docker compose exec ollama ollama pull llama3.2

# Проверьте установленные модели
docker compose exec ollama ollama list
```

### 6. Проверьте работу

```bash
# Посмотрите логи article-service
docker compose logs -f article-service

# Должно быть сообщение: "Ollama доступен"
```

### 7. Протестируйте (опционально)

```bash
# Запустите тестовый скрипт
python3 test_ollama.py
```

## Выбор модели

### Рекомендации в зависимости от ресурсов:

**У вас 8GB RAM:**
- `llama3.2` (3B) - Быстрая, хорошее качество

**У вас 16GB RAM:**
- `mistral` (7B) - Отличное качество
- `qwen2.5` (7B) - Превосходно для текста

**У вас 32GB+ RAM:**
- `llama3.1` (8B) - Очень качественная
- `mixtral` (47B) - Профессиональное качество

### Смена модели:

```bash
# Загрузите новую модель
docker compose exec ollama ollama pull qwen2.5

# Обновите .env
OLLAMA_MODEL=qwen2.5

# Перезапустите сервис
docker compose restart article-service
```

## Сравнение производительности

### OpenAI (gpt-3.5-turbo)
- ⚡ Скорость: ~30-50 токенов/сек
- 💰 Стоимость: $0.002/1K токенов
- 🌐 Требует интернет: Да
- 🔒 Приватность: Данные отправляются на сервера OpenAI

### Ollama (llama3.2, 3B)
- ⚡ Скорость: 10-30 токенов/сек (CPU), 50-100 (GPU)
- 💰 Стоимость: Бесплатно
- 🌐 Требует интернет: Нет (после загрузки)
- 🔒 Приватность: Все данные локально

### Ollama (mistral, 7B)
- ⚡ Скорость: 5-20 токенов/сек (CPU), 30-80 (GPU)
- 💰 Стоимость: Бесплатно
- 🌐 Требует интернет: Нет (после загрузки)
- 🔒 Приватность: Все данные локально
- 📝 Качество: Сравнимо или лучше чем GPT-3.5

## Ускорение с GPU (опционально)

Если у вас есть NVIDIA GPU, раскомментируйте в `docker-compose.yml`:

```yaml
  ollama:
    # ...
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
```

Это ускорит генерацию в 3-5 раз!

## Откат на OpenAI (если нужно)

Если локальная LLM не подходит, вы можете вернуться на OpenAI:

1. Откройте `article-service/rewriter.py`
2. Восстановите код из предыдущей версии
3. Обновите `requirements.txt`, добавив `openai==0.28.0`
4. Обновите `.env` с `OPENAI_API_KEY`
5. Пересоберите контейнер

Или используйте git для отката:
```bash
git checkout <предыдущий_коммит> article-service/
```

## Устранение неполадок

### Ollama не запускается
```bash
docker compose logs ollama
```

Возможные причины:
- Недостаточно памяти
- Конфликт портов (11434)

### Модель не загружается
```bash
docker compose exec ollama ollama pull llama3.2 --verbose
```

### Медленная генерация
- Используйте более легкую модель
- Добавьте GPU поддержку
- Увеличьте RAM

### Out of Memory
- Используйте модель меньшего размера (3B вместо 7B)
- Закройте другие приложения
- Увеличьте swap память

## Часто задаваемые вопросы

**Q: Насколько качество хуже чем у GPT-3.5?**  
A: Модели 7B+ (mistral, qwen2.5) дают сравнимое или даже лучшее качество для рерайта на русском языке.

**Q: Можно ли использовать OpenAI и Ollama одновременно?**  
A: Да, но потребуется модификация кода для поддержки двух провайдеров.

**Q: Сколько времени занимает рерайт одной статьи?**  
A: С llama3.2 на CPU: 1-3 минуты. С GPU: 20-40 секунд.

**Q: Нужно ли всегда держать Ollama запущенным?**  
A: Да, для работы article-service. Ollama потребляет минимум ресурсов в режиме ожидания.
